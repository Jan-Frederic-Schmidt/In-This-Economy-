# In This Economy?

This is a small program for macOS that lets you adjust prices for inflation and calculate inflation rates in 18 countries: Germany, the United States, Canada, Belarus, the United Kingdom, Ukraine, Japan, Mexico, Russia, Brazil, Kazakhstan, the Eurozone, the European Union, Türkiye, France, Greece, India and Spain. Some data (like for the US) dates back to 1913, while other is more recent. 

Also check out InflationKit, my Swift Package used for many of the core features of the app!
